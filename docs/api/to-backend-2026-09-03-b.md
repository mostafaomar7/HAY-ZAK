# الـCORS: السبب مش الـURL — الـorigin بتاعنا مش في القايمة

الـ`base URL` عندنا مظبوط بالظبط زي ما قلتوا، والـNetwork tab بيثبته:

```
Request URL: https://179-198-199-243.sslip.io/api/v1/auth/login
```

يعني مفيش `http://` ومفيش IP خام ومفيش 301 في الـpreflight. التشخيص ده مش
مطابق للي حاصل.

**السبب الحقيقي مكتوب في آخر فقرة في ردّكم نفسه:** التطبيق مرفوع على origin
عام، والعام مش مسموح تلقائيًا.

الصفحة متقدّمة من:

```
http://179.198.199.243
```

وده باين في الـ`Referer` في نفس الصورة.

## نفس الـpreflight بتاعكم، بتلات origins

جرّبنا الأمر اللي بعتّوه بالحرف، وغيّرنا الـ`Origin` بس:

| الـOrigin                          | الرد      | `Access-Control-Allow-Origin` |
| ---------------------------------- | --------- | ----------------------------- |
| `http://localhost:4200`            | `204`     | ✅ موجود                      |
| `https://179-198-199-243.sslip.io` | `204`     | ✅ موجود                      |
| **`http://179.198.199.243`**       | **`200`** | ❌ **مفيش خالص**              |

التالت ده هو اللي المتصفح بيبعته فعلاً. بيرجع `200 text/plain` من غير ولا
هيدر `Access-Control-*`، فالمتصفح بيقطع الطلب ويقول CORS — وده بالظبط اللي
احنا شايفينه.

## المطلوب — واحد من الاتنين

**١. تضيفوا الـorigin ده للقايمة:**

```
http://179.198.199.243
```

أسرع حل، وبيشتغل النهارده.

**٢. الأنضف: نخدم التطبيق من `https://179-198-199-243.sslip.io` نفسه.**

الـorigin ده **مسموح عندكم أصلاً** (جرّبناه فوق، رجع `204` بالهيدر) — لكن
الأهم إنه ساعتها هيبقى **نفس أصل الـAPI**، يعني:

- مفيش CORS من أصله، ولا preflight ولا قايمة تتصان.
- الصفحة تبقى على `https` بدل `http`. دلوقتي كلمة السر بتتكتب في صفحة على
  اتصال مكشوف — وده مش حاجة تعدّي.
- الصور تشتغل من غير أي إعداد زيادة.

لو التاني ممكن من ناحيتكم، هو اللي نرشّحه ومش محتاج تغيير ولا سطر عندنا.

## ملاحظة على شكل السيرفر دلوقتي

`http://179.198.199.243` بيخدم **الواجهة بس**، وفيه SPA fallback بيرجّع
`index.html` بـ`200` لأي مسار. يعني:

```
GET http://179.198.199.243/api/v1/public/cities  → 200 text/html  ← الواجهة، مش الـAPI
GET http://179.198.199.243/uploads/units/…/x.png → 200 text/html  ← الواجهة برضه
```

ده بيخلي أي غلط في المسار يبان كأنه نجح — فلو حد جرّب الـAPI على العنوان ده
وشاف `200`، ده مش الـAPI. الـAPI على `https://179-198-199-243.sslip.io` بس،
وهناك نفس المسارات بترجع `application/json` صح.

لو خدمتوا الواجهة من الاسم الـsslip المشكلة دي بتختفي هي كمان، لأن
`/api/v1` و`/uploads` هيبقوا قبل الـfallback على نفس الـvhost.
