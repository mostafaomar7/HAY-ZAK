المسارات الأربعة

كل عقدة في المخطط رابط يفتح الشاشة نفسها. تمثّل الفروع الحمراء نقاط الفشل، والذهبية مراحل انتظار قرار الإدارة.

5a

المسار 1 — من التسجيل إلى نشر أول مساحة

التسجيل ← رمز التحقق ← اللوحة — محجوبة
نقطة فشل: بيانات بنكية ناقصة تنبيه حاجب أعلى اللوحة، وزر «إضافة مساحة» معطّل مع تلميح يوضّح السبب. عرض التنبيه الحاجب
البيانات البنكية ← اللوحة — مفتوحة ← إضافة مساحة (3 خطوات)
نقطتا فشل داخل المعالج يُرفض الآيبان غير الصحيح داخل الحقل قبل الإرسال · تمنع الصورة الواحدة الإرسال برسالة صريحة · يحفظ انقطاع الاتصال مسودة يمكن استئنافها.
خطأ الآيبان منع الإرسال بصورة واحدة انقطاع الاتصال والاستئناف
قيد مراجعة الإدارة ← إشعار الموافقة ← الوحدة منشورة
الفرع البديل: رفض الإعلان إشعار ببيان السبب ← بطاقة مرفوضة تعرض سبب الإدارة ← «تعديل وإعادة الإرسال» ← العودة إلى حالة «قيد المراجعة».
إشعار الرفض البطاقة المرفوضة
5b

المسار 2 — دورة حياة الطلب

إشعار طلب جديد ← الطلبات ← التفاصيل — المستأجر مقفل
لا يملك المؤجر أي إجراء في هذه المرحلة: شارة حالة ونص «الطلب قيد مراجعة إدارة المنصة» فقط، مع حجب بيانات المستأجر.
إشعار الموافقة ← التفاصيل — المستأجر مفتوح ← بدء الحجز — نشط ← انتهاء الحجز — مكتمل ← يظهر في المستحقات
الفرع البديل: رفض الإدارة ← الحالة «مرفوض ومسترجَع» وإعادة المبلغ إلى المستأجر، دون ظهوره ضمن المستحقات.
5c

المسار 3 — التحصيل والتحويل

انتهاء الحجز ← قيد الانتظار ← قيد التنفيذ ← إشعار التحويل ← محوّل + المرجع البنكي
الفرع البديل: تجميد التحويل بيانات بنكية ناقصة أو اسم غير مطابق ← الحالة «مجمّد» مع بيان السبب وزر «تصحيح البيانات البنكية» ← يعود المبلغ إلى مسار التحويل تلقائياً بعد التصحيح.
صف «مجمّد» في الجدول تصحيح البيانات البنكية
5d

المسار 4 — إدارة المساحة

المساحات المسجّلة ← تفاصيل المساحة ← تعديل إيقاف مؤقت أرشفة
قاعدة: وحدة عليها حجز نشط لا تُؤرشف توقف محاولة الأرشفة العملية وتوضّح السبب وتاريخ انتهاء الحجز، مع إتاحة «الإيقاف المؤقت» بديلاً يمنع الطلبات الجديدة دون المساس بالحجز القائم. عرض رسالة تعذّر الأرشفة
